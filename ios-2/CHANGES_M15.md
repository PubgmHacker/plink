# Plink — M15: Модерация комнаты + редизайн создания

## 1. Верхний бар модерации в комнате (как таббар над чатом)
- **Новый файл** `Plink/Features/WatchRoom/RoomModerationBar.swift` — панель «Кто может войти» поверх плеера/чата:
  - 4 режима: **Публичная / Закрытая (пароль) / По ссылке / Для друзей** (как у Rave).
  - Для «Закрытая» — инлайн-поле пароля с кнопкой «Готово».
  - Автоматически показывается хосту **один раз** после создания комнаты (через 1,2 с), сам скрывается через 8 с, чтобы не мешать.
  - Повторный вызов — кнопка-щит (`shield.lefthalf.filled`) в верхнем хроме плеера (видна только хосту, подсвечивается акцентом при открытом баре).
  - Цвета следуют теме комнаты (PlinkRoomAccent).
- `WatchRoomModel`: `roomPrivacy`, `moderationBarVisible`, `loadPrivacy()`, `setPrivacy(_:password:)` — локальное применение + PATCH на сервер + рассылка гостям через чат-протокол (маркер `\u{2063}plink.priv\u{2063}`), приём и скрытие служебных сообщений.
- `WatchRoomScreen`: overlay бара (zIndex 480, transition сверху), автопоказ один раз на комнату (UserDefaults `plink.modBarShown.<roomId>`).
- `Room.swift`: новый режим `RoomPrivacy.friendsRoom` («Для друзей»), декодер `"friends"`.
- `RoomService.updatePrivacy(roomID:privacy:password:)` — PATCH `rooms/:id/privacy`.

## 2. Бэкенд (изменён в этом апдейте!)
- `src/routes/rooms.ts`:
  - **Новый роут** `PATCH /api/rooms/:id/privacy` — только хост; валидация режима; для `private` — хеширование нового пароля или сохранение старого; для остальных режимов пароль сбрасывается.
  - **Join-проверка «для друзей»**: при `privacy = friends` вход разрешён только друзьям хоста (проверка Friendship в обе стороны), иначе 403 `FRIENDS_ONLY`.

## 3. Редизайн создания комнаты и выбора сервисов
- **Новый файл** `Plink/Views/Home/ServicePickerCarousel.swift`:
  - `ServiceRegion` — 🇷🇺 российские / 🌍 зарубежные / 🔗 универсальные.
  - `ServicePickerFilter` + `ServiceFilterChips` — чипы-фильтры: Все / 🇷🇺 Российские / 🌍 Зарубежные / Бесплатные / По подписке.
  - `ServiceCarouselCard` — крупные карточки 200×168 в фирменном градиенте сервиса, лого, бейдж региона, «Без подписки»/«Подписка», «✓ Вход выполнен», анимация нажатия.
  - `ClipboardVideoCard` — если в буфере обмена ссылка на видео, показываем карточку «Вставить из буфера» с автоопределением сервиса.
  - `RecentServicesStore` — до 4 недавних сервисов (UserDefaults), строка быстрого выбора «НЕДАВНИЕ».
- `RoomCreationView.swift` — переработан шаг выбора сервиса:
  - Горизонтальные карусели «БЕЗ ПОДПИСКИ» и «С ПОДПИСКОЙ · КИНОТЕАТРЫ» с постраничным скроллом (`viewAligned`), фильтры по региону и подписке, секция «ДРУГОЕ» (ссылка/браузер) сохранена.
  - Автоподстановка ссылки из буфера обмена → сразу шаг настройки.
- Шаг настройки комнаты:
  - Вместо тумблера «открытая/закрытая» — сетка 2×2 из карточек 4 режимов приватности + поле пароля для закрытой комнаты (та же модель, что и бар модерации в комнате).
  - Показ ошибки создания прямо в форме, возврат на шаг настройки при сбое.
- **Фикс**: добавлен `init(onRoomCreated:)` с настоящим сетевым созданием комнаты (`performCreate`): сборка MediaItem (YouTube — извлечение videoId, обложка hqdefault; прочее — прямая ссылка), имя по умолчанию, приватность + пароль, haptics, обработка ошибок. Ранее 5 экранов вызывали несуществующий инициализатор.
- `selectService` теперь запоминает сервис в «недавних».
