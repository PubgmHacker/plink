# Plink — пакет улучшений M13

Реализованы все пункты из списка улучшений, кроме реферальной системы (по запросу) и всего, что требует платного аккаунта Apple Developer.

---

## 1. Умный JS-мост для кино-сервисов (`Plink/Playback/EmbedPlaybackController.swift`)
- Поиск `<video>` теперь заглядывает в открытые shadow-root'ы и same-origin айфреймы — кастомные плееры онлайн-кинотеатров больше не «невидимы».
- Выбирается «главное» видео: самое длинное по длительности, затем самое крупное на экране (рекламные ролики-превью отсеиваются). Найденный элемент кэшируется, пока он в DOM.
- Мост сам переустанавливается после SPA-навигации (переход к другой серии внутри кинотеатра).
- Новое свойство `hasBridgedVideo` — приложение знает, точная синхронизация или best-effort.
- `supportsRateCorrection: true` — кино-сервисы теперь синхронизируются плавным P-контроллером из M12 (микро-подстройка скорости ±5%), а не жёсткими перемотками.
- Неточные перемотки используют `fastSeek()`, если плеер его поддерживает.

## 2. Голосования в комнате (`Features/WatchRoom/RoomPolls.swift` + интеграция)
- Быстрые опросы «что смотрим дальше?»: 2–4 варианта, живой подсчёт голосов, закрытие автором, автоскрытие результатов через 8 с.
- События едут поверх существующего чат-протокола (невидимый маркер + JSON) — бэкенд менять не нужно, старые клиенты просто игнорируют такие сообщения.
- В комнате: кнопка создания опроса (под кнопкой выхода), карточка опроса сверху, композер-шторка.

## 3. Watch-party статистика (`Views/Profile/WatchStatsView.swift`)
- Экран «Мы посмотрели»: сеансы, часы у экрана, уникальные видео, среднее досматривание / любимый источник, топ-5 просмотров с барами.
- Кнопка «Поделиться статистикой» (ShareLink) — бесплатная виральность.
- Вход — иконка графика в шапке истории просмотров в профиле. Считается локально, бэкенд не нужен.

## 4. Баннер переподключения (`WatchRoomScreen.swift`, `RealtimeClient.swift`, `WatchRoomModel.swift`)
- При обрыве связи в комнате появляется капсула «Переподключение… N сообщ. в очереди».
- Очередь офлайн-сообщений из M12 теперь видима пользователю — комната не выглядит «сломанной».

## 5. Виджет «Ближайший сеанс» (`PlinkWidget/`)
- Новый WidgetKit-таргет (small + medium): название и время ближайшего запланированного сеанса прямо на домашнем экране.
- Данные идут через app group `group.com.syncwatch.plink` (добавлены entitlements обоим таргетам); `ScheduledSessionsService` зеркалит расписание и дёргает обновление виджета при каждом изменении.
- Таргет описан в `project.yml` — генерируется штатным `xcodegen generate`.

## 6. Прогон P-контроллера в симуляторе (`scripts/controller-sim.mjs`)
Симуляция 100 прогонов по 90 с (джиттер сети, столл 500 мс, скачок часов +250 мс):

| Метрика | Старый ступенчатый | Новый P-контроллер (M12) |
|---|---|---|
| Медианный дрифт (устоявшийся) | 92 мс | **17 мс** |
| p95 дрифт | 110 мс | **28 мс** |
| Сходимость <80 мс (холодный старт) | 38.3 с | **7.6 с** |
| Восстановление после столла 500 мс | 25.5 с | **10.8 с** |
| Восстановление после скачка +250 мс | 16.1 с | **6.1 с** |

Запуск: `node scripts/controller-sim.mjs [число прогонов]`.

## 7. Скриншот-тесты тем (`PlinkTests/ThemeSnapshotTests.swift`)
- Пиксельные снапшоты каталогов V4-тем и живых тем Plink+ через swift-snapshot-testing (добавлен в `project.yml`).
- Включаются только при `SNAPSHOT_TESTS=1` — обычный CI не замедляется.
- Дополняют текстовые тесты тем из M12: теперь ломающий цвет/градиент поймается до релиза.

## 8. Алерты keep-alive (`.github/workflows/keep-alive.yml`)
- Если пинг бэкенда падает, workflow теперь создаёт/обновляет GitHub Issue с меткой `backend-alert` — падение видно сразу, а не через жалобы друзей.

## 9. Android-паритет (`android-client/`)
- `OrderedSyncController.kt`: тот же P-контроллер, что на iOS (мёртвая зона 40 мс, мягкая зона 120 мс, коррекция ±5%, адаптивный речек 1–2 с).
- `PlinkRealtimeClient.kt`: офлайн-очередь чата (до 50 сообщений) с автофлашем при переподключении — как на iOS.

## 10. E2E happy-path тест (`backend/src/tests/integration/happyPath.e2e.test.ts`)
- Полный сценарий: регистрация двух пользователей → создание комнаты → вход по коду → WS-подключение обоих → play у хоста → зритель получает синхронизацию → чат доходит → pause.
- Включается через `E2E=1` (нужны поднятые Postgres/Redis из `tests/integration/docker-compose.yml`).

## 11. Пейволл-моменты (`V4AppearanceView.swift`, `RoomSetupView.swift`)
- Тап по замоченной теме/баблу теперь открывает контекстный пейволл Plink+ вместо тупикового тоста.
- При создании комнаты под степпером участников — мягкий апселл «Нужно больше мест? С Plink+ — до 50».

## Как собрать
```bash
cd plink-ios-m13
xcodegen generate   # создаст проект уже с таргетом PlinkWidget
open Plink.xcodeproj
```
Виджет и app group работают в симуляторе без платного аккаунта разработчика.
