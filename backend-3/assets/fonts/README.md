# Самохостинг шрифтов лендинга

У сайта строгий CSP (`default-src 'none'`), поэтому Google Fonts и любые другие
CDN запрещены: шрифты лежат в репозитории и отдаются своим же роутом
`GET /assets/fonts/:file` (`src/routes/assets.ts`, белый список имён,
`Cache-Control: public, max-age=31536000, immutable`).

## Что здесь лежит

| Файл | Гарнитура | Начертание | Назначение |
|---|---|---|---|
| `playfair-italic-{latin,latin-ext,cyrillic}.woff2` | Playfair Display | только italic, вариативный 400–800 | дисплейные заголовки |
| `inter-{latin,latin-ext,cyrillic}.woff2` | Inter | normal, вариативный 300–700 | интерфейс и текст |

Каждый файл — отдельный сабсет; в CSS они подключены через `@font-face` с
`unicode-range`, поэтому браузер скачивает только нужное: на русской странице
это `cyrillic` + `latin` (~126 КБ), латиница-расширенная не загружается вовсе.

## Почему именно эти гарнитуры

Референсные промты владельца используют Instrument Serif, **но у него нет
кириллицы**, а весь сайт русскоязычный. Playfair Display — ближайший
высококонтрастный дисплейный сериф с полноценной кириллицей и настоящим
италиком (он же используется в референсе Lithos).
